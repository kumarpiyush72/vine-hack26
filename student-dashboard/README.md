# CTRL + CHAOS ⚡
### An Interactive Digital Fever Dream for Vine Hackathon 2026

> **"THE WEBSITE IS ALIVE. EVERY CLICK MAKES REALITY LESS STABLE."**

Built under `student-dashboard`, **CTRL + CHAOS** is an experimental, maximalist, retro-cyberpunk interactive experience that progressively loses its mind as you interact with it.

---

## 🎮 How to Run

```bash
# Navigate to project directory
cd vine-hack26/student-dashboard

# Install dependencies (React 19, Framer Motion, Canvas Confetti, Lucide)
npm install

# Start development server
npm run dev
# -> Runs at http://localhost:5173/

# Run linter (0 errors, 0 warnings)
npm run lint

# Production build
npm run build
```

## 🌟 Signature Features & Interactions

### 1. The Central Chaos Engine (6 Phases)
- **Phase 0: Suspiciously Normal** (0 clicks) — 100% Reality Integrity, minimal layout, cryptic system markers.
- **Phase 1: Denial** (1–3 clicks) — Sarcastic button labels, initial warnings, click tracker begins.
- **Phase 2: Instability** (4–8 clicks) — Draggable retro dialogs appear, the main button starts dodging the cursor.
- **Phase 3: Reality Collapse** (9–15 clicks) — Layout warps, controlled screen shake, digital pet companion reacts frantically.
- **Phase 4: Absolute Nonsense** (16–24 clicks) — Absurd status messages ("Haunted by Unicode", "Pigeons arbitrating cursor").
- **Phase 5: Beyond Reality** (25+ clicks) — Singularity collapse, cosmic gateway primed.

### 2. The Liar Button
- Impossible button `[ DO NOT CLICK ]` that taunts the user with over 15 sarcastic rotating labels.
- In Phase 2+, button playfully dodges the cursor with spring physics and audio wobble.

### 3. Popup Apocalypse
- Draggable Windows 95 / Cyber style dialog windows with hilarious internet copywriting:
  - *Suspicious Potato Alert*
  - *Cognition Kernel Panic (Brain Cells Unresponsive)*
  - *The Moon Has Rejected Your Application* (Hides Secret #2 ⭐)
  - *Sweepstakes: You Won $0.00*
  - *Uninstall Tuesday Prompt*
  - *Pixel Unionization Notice*

### 4. The Void Button `[ OPEN THE VOID ]`
- Dark cosmic singularity portal with sub-bass drone and gravitational vortex.
- Surrounding interface warps inward toward the event horizon.
- Hides Secret #3 (Miniature Black Hole 🕳️).
- Surreal dialogue: *"The Void stares back... and says: 'Could you keep it down? We are trying to sleep.'"*

### 5. Glitchkin: The Cursor Creature
- Custom SVG digital pet that smoothly follows mouse movements with physics lag.
- Expressive eyes track cursor velocity, winks on clicks, antenna glows in high chaos.
- **Secret Poke Mechanic**: Clicking the creature 5 times yields Secret #4 (Strange Smiley 👾) and an achievement.

### 6. The Button Cemetery
- Solemn graveyard modal honoring UI buttons that gave their lives for your clicks:
  - *The Close Button (X)*
  - *Submit Button (Died of form validation fatigue)*
  - *Free WiFi Button (Airport captive portal hell)*
  - *Accept Cookies [All]*
- Click tombstones to Pay Respects (`+5` Chaos Pixels).

### 7. The Useless Shop
- Retro cyber storefront where users spend **Chaos Pixels** on hilarious upgrades:
  1. **Premium Golden Cursor**: 24K gold diamond cursor with sparkling trails.
  2. **Emotional Support Pixel**: Floating pet pixel that gives encouraging affirmations.
  3. **One Extra Brain Cell**: Upgrades HUD counter from `UNAVAILABLE` to `ACTIVE: 1`.
  4. **A Suspicious Banana**: Dancing pixel banana that chimes on click.
  5. **Certified Chaos Licence**: Official Reality Disruption Agent badge.
  6. **Absolutely Nothing**: Deducts 50 pixels with 100% customer satisfaction.

### 8. The Fake Crash (Simulated BSOD)
- Critical Error 404 Kernel Panic simulation (`TOO MUCH INTERNET DETECTED`).
- Interactive memory dump stack trace containing Secret #5 (Pixelated Skull 💀).
- Glitching progress bar that buffers to infinity.
- `[ OVERRIDE & ESCAPE THE SIMULATION ]` button safely returns without browser reload.

### 9. Secret Discovery System (5 Collectibles)
Collect all 5 hidden cosmic artifacts:
1. 👁️ **The Omniscient Eye**: In the footer / technical system version marker.
2. ⭐ **The Broken Star**: Inside the rejected Moon application popup.
3. 🕳️ **Miniature Black Hole**: In the center of the Void vortex.
4. 👾 **Strange Digital Smiley**: Poking Glitchkin 5 times.
5. 💀 **Pixelated Skull**: Inside the Fake Crash stack trace.

### 10. The Endgame: THE FORBIDDEN DIMENSION
- Unlocked when all 5 artifacts are collected (or via Demo Bar).
- Inverted hyper-psychedelic neon matrix theme, negative integrity (`-420.69%`).
- **The Universe Detonator**: Giant red button triggering supernova confetti explosions and awarding the official **Certificate of Universal Omnipotence**.

### 11. Retro Cheat Codes & Secret Sequences
- **Konami Code**: `↑ ↑ ↓ ↓ ← → ← → B A`
- **Typing Code**: Type `chaos` anywhere on keyboard
- **Touch / Mobile Shortcut**: Triple-tap the `CHAOS.OS v0.0.404` badge in the top-left HUD.

### 12. Procedural Web Audio Synthesizer
- 100% self-contained zero-dependency audio engine using the native Web Audio API (no external MP3/WAV files that can fail to load).
- Snappy 8-bit blips, pitch drops, glitch frequency modulation, sub-bass drones, and coin chimes.
- Starts **MUTED** by default with an instant speaker toggle in the HUD.

  - Jump directly to **P0, P1, P2, P3, P4, P5** in 1 click.
